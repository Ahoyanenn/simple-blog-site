# 鳶職人が選ぶ道具ラボ

鳶職人向けの専門アフィリエイトサイトです。安全靴・作業着・腰道具・工具・空調服・ハーネス・手袋・防寒着などを、鳶職人目線のランキング形式で紹介する静的サイトです。

## サイト方針

- HTML/CSS/JavaScriptのみで構成
- WordPressやバックエンド、会員登録機能は不使用
- Netlifyの無料プランで公開できる静的サイト
- Amazon・楽天アフィリエイトリンクを各商品カードのボタンへ差し替え可能
- スマホでランキングカード、比較表、アフィリエイトボタンが見やすい構成

## ファイル構成

```text
.
├── index.html              # トップページ
├── categories.html         # カテゴリ一覧ページ
├── safety-shoes.html       # 安全靴ランキング
├── workwear.html           # 作業着ランキング
├── airwear.html            # 空調服・暑さ対策ランキング
├── waist-tools.html        # 腰道具・工具ランキング
├── harness.html            # ハーネス・安全帯ランキング
├── gloves.html             # 手袋・革手ランキング
├── winter-rainwear.html    # 防寒着・雨具ランキング
├── assets/
│   ├── css/style.css       # 共通デザイン
│   ├── js/main.js          # スマホメニュー・トップへ戻るボタン
│   └── images/             # 画像追加用フォルダ
└── README.md
```

## Netlifyにアップロードするファイル

Netlifyで公開するときは、リポジトリ直下の以下を同じ階層のままアップロードしてください。

- `index.html`
- `categories.html`
- `safety-shoes.html`
- `workwear.html`
- `airwear.html`
- `waist-tools.html`
- `harness.html`
- `gloves.html`
- `winter-rainwear.html`
- `assets/` フォルダ一式

ドラッグ＆ドロップで公開する場合は、このプロジェクトフォルダ全体をZIP化するか、上記HTMLファイルと `assets` フォルダをまとめてアップロードしてください。`README.md` は公開に必須ではありません。

## アフィリエイトリンクの差し替え

各商品カードにある以下のボタンの `href="#"` を、Amazonアソシエイトや楽天アフィリエイトで発行したURLに差し替えてください。

- `Amazonで見る`
- `楽天で見る`

商品画像を使う場合は `assets/images/` に画像を入れるか、各アフィリエイトサービスが発行する画像付きリンクに差し替えてください。

サイト内には以下の注意書きを掲載しています。
